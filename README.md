# joeystdio Homebrew Tap

Official Homebrew Tap for macOS utilities by [@joeystdio](https://github.com/joeystdio):
- **[GhostMouse](https://github.com/joeystdio/GhostMouse)** — Invisible stealth mouse mover & awake utility for macOS
- **[PortRadar](https://github.com/joeystdio/PortRadar)** — Menu bar localhost & dev port manager for macOS
- **[Envy](https://github.com/joeystdio/envy)** — Environment variables & secrets for your terminal and AI coding agents

## Install

```bash
brew tap joeystdio/tap
brew install --cask ghostmouse
brew install --cask portradar
brew install --cask envy
```
